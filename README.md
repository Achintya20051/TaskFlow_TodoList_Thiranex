# TaskFlow — To-Do List Application

A responsive, client-side task management app built with HTML, CSS, and JavaScript.

## Features
- Full CRUD: create, read, update, and delete tasks
- Mark tasks completed or active
- Filter by All, Active, and Completed
- Persist data with `window.localStorage`
- Dynamic DOM manipulation and delegated event listeners
- Responsive layout

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — application logic and localStorage

## How to Run
Keep all three files in the same folder, then open `index.html` in a browser. No backend or installation is required.
